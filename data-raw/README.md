
This folder originally contains the raw MODIS, SRTM and ERA5-Land data. Note that these need to be copied manually (the radiation index used for the thesis has been updated and is not available anymore). This folder is empty because the data files are too large for GitHub. Contact me or GECO Bern if you wish receive the raw datasets.
The R scripts are scripts for pre-processing the data (to .rds files that are stored in "data").
